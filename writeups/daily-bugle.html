Attack Chain Summary

  1. Reconnaissance & Web Enumeration:
    - nmap -sT -sV -sC 10.48.187.164 -Pn revealed SSH (Port 22), Apache 2.4.6 with Joomla CMS (Port 80), and MariaDB (Port 3306).
    - Identified Joomla version 3.7.0.
  2. Initial Foothold (Joomla SQLi & Template RCE):
    - Exploited CVE-2017-8917 (SQL injection in com_fields) via joomblah.py to extract Jonah's bcrypt hash.
    - Cracked Jonah's hash with John the Ripper and rockyou.txt ➔ jonah:********.
    - Logged into the Joomla administration panel, modified the Beez3 template (index.php), and injected a PHP reverse shell.
    - Received reverse shell as user apache.
  3. Lateral Movement to jjameson:
    - Searched for stored credentials using grep -rn "password\|passwd\|pass=" /var/www/ 2>/dev/null.
    - Discovered MySQL configuration password: ********.
    - Switched user via su jjameson and retrieved the user flag:
    cat user.txt ➔ ********************************.
  4. Privilege Escalation to Root (Sudo Yum Plugin):
    - sudo -l showed jjameson can run (ALL) NOPASSWD: /usr/bin/yum.
    - Abused GTFOBins Yum custom plugin injection to execute a root shell.
    - Retrieved root flag: cat root.txt ➔ ********************************.

6. Security Mitigations & Remediation

Vulnerability Impact Recommended Remediation
Joomla SQL Injection (CVE-2017-8917) Remote database extraction and admin takeover. Upgrade Joomla! to version 3.7.1 or higher.
Password Reuse Lateral movement from apache to jjameson. Ensure administrative database credentials are unique and differ from system user passwords.
Sudo NOPASSWD on Package Manager (yum) Local Privilege Escalation to root. Remove package management utilities from sudoers.
